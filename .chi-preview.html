Main flow

  2. GET /articles _examples/rest/main.go:80GET /articles triggers ListArticles, which returns a list of articles.
  3. POST /articles _examples/rest/main.go:81POST /articles triggers CreateArticle, which binds the request body and creates a new article.
  4. GET /articles/{articleID} _examples/rest/main.go:86GET /articles/{articleID} triggers GetArticle, which retrieves a single article by ID.
  5. PUT /articles/{articleID} _examples/rest/main.go:87PUT /articles/{articleID} triggers UpdateArticle, which updates an existing article.
  6. DELETE /articles/{articleID} _examples/rest/main.go:88DELETE /articles/{articleID} triggers DeleteArticle, which removes an article.
