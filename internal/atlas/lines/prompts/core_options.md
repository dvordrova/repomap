# The part-role question's options with their own criteria

The option of the question "`role` for `row`" that carries its criteria:
what it is, what it includes, what it is not for, and examples. The request
sends them as the option's criteria; the task defines the other options.

## example

What: The part is code the program ships for its users to read, copy or start from, not code the program itself runs to do its work.

Includes: sample or template implementations of the program's extension points, example plugins, demos and tutorials, starter files a command copies into a user's project

Not for: implementations the program runs to do its work, even when it loads them by name from its settings and no other part calls them; tests and test fixtures

Examples:
- a sample plugin a new user copies and edits into their own
- a template handler that shows how to write one
- a demo program that shows how to use a library
