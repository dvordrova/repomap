# Decision: Golden Mechanism v0.2 local sequence and publication loop

**Status**: Approved for implementation

**Approved by**: Repository owner in the current implementation session

## Product question

Can one separately proven, same-function and same-branch local sequence fact
close the Caddy directory-listing mechanism's remaining temporal-support gap
and let the accepted artifact complete the existing canonical replay, report,
evidence, and Super Search path?

## Fixed inputs

- Candidate: `File Server Directory Listing`.
- Candidate ID: `semantic-candidate-8d47b99879d5cfbc1413052a`.
- Question: `How does the file server generate and sort directory listings?`.
- Caddy revision: `873fac5fc094fe538d0c477509127bb321d51a32`.
- The six v0.1 `gmf-*` facts retain their identity and meaning.
- The saved bounded probe is the only input from which the new local sequence
  may be derived; the probe and repository analyzers are not rerun.

## Approved implementation

1. Determine from the saved syntax observations and retained source whether
   the browse predicate and direct browse call belong to one local branch of
   one function. Do not infer global runtime order.
2. If proven, add exactly one separate deterministic fact with `sequence`
   capability, same-function/same-branch scope, exact branch and call evidence,
   and explicit exclusions for branch selection, call success, and wider
   runtime order. Do not add sequence capability to the old entry fact.
3. Add regression tests that accept the exact same-branch relation and reject
   unrelated statements, sibling branches, and different functions.
4. Keep the six-fact fixture unchanged and create a versioned seven-fact
   fixture containing only the new fact in addition.
5. Change only the temporal fragment of the Golden prompt and bump its version.
   Existing parsing, lineage, reference, capability, unresolved-gap, and intent
   validation remains strict.
6. Make exactly one fresh synthesis call with the same provider, model,
   candidate, question, artifact kind, rubric, and six old facts plus the new
   sequence fact. No retry, response rewrite, fallback, or provider switch.
7. In addition to the existing validator, require the entry sequence claim to
   cite the new fact and stay within its local conditional scope.
8. On acceptance only, save the canonical supplement and semantic record,
   publish through the existing report path, then prove replay without provider,
   probe, or repository analyzers.
9. Verify the existing HTML, evidence navigation, five fixed natural-language
   searches, and exact source-path precedence without changing search.
10. Score only the accepted canonical artifact and save an ignored supervisor
    report.

## Hard exclusions

- no opportunity scan, targeted-probe rerun, package loading, SSA, call graph,
  pointer analysis, runtime-surface discovery, or global CFG;
- no new artifact kind, renderer, search path, or search-algorithm change;
- no cache work, MCP, other mechanism, Ollama, provider/model change, response
  post-processing, or validator weakening;
- no second fresh synthesis call.

## Stop condition

If the bounded local sequence is not deterministically proven, do not call the
model. If the one fresh response is rejected, preserve exact diagnostics and
stop without publication or a second call.

## Acceptance

The experiment succeeds only when the local relation is independently proven,
the single fresh response passes all existing and local-scope validation, the
canonical artifact scores at least 3/4, replay works without model or analyzers,
the existing HTML exposes the mechanism and evidence, five semantic queries
rank it first, and exact source-path search still ranks its location first.
