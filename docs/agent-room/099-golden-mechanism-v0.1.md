# Decision: Golden Mechanism v0.1 publication loop

**Status**: Approved for implementation

**Approved by**: Repository owner in the current implementation session

## Product question

Can the already demonstrated Caddy directory-listing mechanism pass one
aligned prompt/validator contract and travel through the existing canonical
semantic artifact, replay, report, evidence, and Super Search path?

## Fixed inputs

- Candidate: `File Server Directory Listing`.
- Candidate ID: `semantic-candidate-8d47b99879d5cfbc1413052a`.
- Question: `How does the file server generate and sort directory listings?`.
- Caddy revision: `873fac5fc094fe538d0c477509127bb321d51a32`.
- The six saved `gmf-*` facts and their evidence are a fixed fixture.
- The rejected v0 response is a regression fixture, never a canonical result.

## Approved implementation

1. Reproduce the three v0 failures independently: conservative slash/path
   detection, ordering language without sequence support, and implicit
   limitation wording.
2. Preserve repository-reference and sequence safety. Align the Golden
   Mechanism prompt with those checks and require one explicit canonical
   `Evidence gap:` marker for unresolved Golden Mechanism prose.
3. Keep the reducer's existing top-level issue codes while recording a bounded
   list of precise, non-secret diagnostic reasons.
4. Bump the Golden Mechanism prompt version and locally replay the exact old
   response. It may remain rejected when the rejection is precise and safe.
5. Make exactly one fresh synthesis call with the same candidate, question,
   rubric, facts, provider, model, and fan-in semantics.
6. On acceptance, publish through the existing supplemental facts, semantic
   record, report generation, artifact detail, evidence, canvas focus, and
   search contracts. Add no artifact type or renderer.
7. Prove replay from the saved canonical facts and semantic record without a
   provider call, repository analysis, probe, package loading, SSA, call graph,
   or runtime-surface discovery.
8. Verify the five fixed English/Russian semantic queries and preserve exact
   path search precedence.
9. Score only the accepted canonical artifact and save an ignored supervisor
   report. Stop after one fresh model failure.

## Hard exclusions

- no opportunity scan;
- no second targeted probe;
- no package loading, SSA, call graph, pointer analysis, or runtime discovery;
- no provider/model/configuration change;
- no search algorithm or architecture-canvas redesign;
- no cache, MCP, new artifact kind, or broad fan-in refactor;
- no second synthesis call after a fresh rejection.

## Acceptance

The experiment succeeds only if the fresh response passes JSON, opaque-ID,
repository-reference, capability, claim-basis, and intent validation; the
canonical artifact scores at least 3/4; saved replay works without provider or
repository analysis; the existing HTML exposes the artifact and evidence; all
five semantic queries rank it above side facts while exact source-path search
still wins; and the baseline remains usable after semantic failure.
