## Failures this decision closes

1. A current Adjudication response with zero valid cards could fail while its
   accepted Scout prefix remained saved. The runtime then swallowed a failed
   result-encoding error as if a durable status existed, and report publication
   aborted. Syn reproduced this in the full corpus.
2. An ordinary integrity failure returned before printing the shared terminal
   `Run: state: failed`, while the external corpus wrapper called every exit-zero
   report `PASS` without consuming the product classifier.
3. Current reports warned about an absent retired `orientation_report.json` and
   embedded the operator's absolute path in shareable HTML.
4. A source action could be visibly enabled by an embedded snippet but do
   nothing on a generic host. Package-only Architecture components also retained
   exact `package_targets` that the inspector never exposed.
5. The visible Canvas count and accessible hint could disagree; raw Study
   concentration markers leaked internal portfolio accounting; and Study copy
   claimed local reduction had confirmed model meaning when it had only checked
   refs, structure, and source bindings.

## Approved correction

- Zero-survivor Adjudication persists a status-only
  `response_validation_failed` outcome with exact item-local rejection counts.
  No accepted result or themes artifact is invented. Report, manifest, and HTML
  still publish and the shared classifier returns `DEGRADED` / `study_failed`.
  Unexpected persistence errors remain terminal instead of being swallowed.
- Every ordinary command that exits before publication emits the shared closed
  FAILED terminal state. `dev corpus` remains the authority for READY/DEGRADED/
  FAILED; wrappers may say only that artifacts were published until they consume
  its verified `corpus_acceptance.json`.
- Absence of the retired orientation sidecar is normal and silent. A present but
  unreadable or malformed sidecar still produces an operational warning. Public
  HTML never needs a missing-file absolute path to explain current product state.
- Generic-host source actions prefer the exact embedded snippet when present;
  static GitHub/GitLab and manifest-authorized editor actions retain their
  existing authority. If a component has no exact symbol action, its already
  verified package target is exposed as the typed code start. No browser path
  inference is added.
- The mobile Map opens the component list when its Canvas is hidden, qualified
  source actions wrap without an inspector scrollbar, and visible/accessibility
  counts derive from the same current Canvas collection.
- Study shelf/detail wording says exactly what is known: source anchors are
  attached, while theme wording is model interpretation that must be checked
  against the cited code. Internal concentration markers are not product copy.
  This correction does **not** claim semantic entailment; unsafe statements such
  as Age's generic overwrite-protection claim remain a separately recorded
  backend integrity blocker.
