# 283 — Generic model-assisted entry surfaces

**Status:** ACTIVE (owner-authorized, 2026-08-10)

**Preserves:** D273's single ordinary framework-free Go path; D248/D259's
single bounded entry-call provider call, refs-only response, exact local
restoration and item-local salvage; D281's neutral Canvas and explicit
Entrypoints context; D283's exact-trigger presentation join; all current
target, repository-state, source-authority, secret-scan and manifest bounds.

**Supersedes:** D248 only where it prohibited a product surface projection,
and D273 only where it required third-party handlers and fresh CLI commands to
remain absent even when the existing generic entry-call call can classify
bounded local syntax facts. It does not restore framework catalogs, Cobra
readers, command traces or a framework mode.

## Product failure

The ordinary generic entry-call stage already finds useful framework-neutral
anchors such as `routers.InitAPI -> web.Router` and
`main -> ... -> cobra.(*Command).Execute`. Its response, however, may select
only call-family refs. Exact command and route syntax is discarded before the
model can classify it, so fresh Echo and Cobra runs publish only `main` even
though the existing model call has reached the relevant construction and
registration code.

Re-enabling one hard-coded adapter per framework would duplicate the generic
stage and make product coverage depend on a growing framework allowlist.

## Approved ordinary contract

- Reuse the existing `entry_call_compression` call. There is no second model
  call, retry, analysis mode or user flag.
- During the same already-loaded Go syntax/types/SSA pass, retain a separately
  bounded candidate reservoir from the selected executable and its exact
  repository-owned process/init closure:
  - direct calls with a safe short literal/token fact and a callable fact;
  - lower-priority direct calls with an exact `/...` string and an independent
    string/token fact, even when no callable can be resolved;
  - keyed composite literals with a safe short string fact and a callable
    fact.
- Candidate admission is structural. It contains no Echo, Cobra, Gin, chi or
  other framework symbol/name allowlist.
- The provider sees request-local candidate, fact, kind and slot refs plus
  bounded sanitized sketches. It may classify a candidate as a CLI command or
  HTTP route and bind advertised facts to advertised semantic slots.
- The provider returns no command/path/method/handler text, source location,
  trigger ID, parent ref, framework, title, explanation, score or ordering.
  Exact values, locations, identity, stable IDs and canonical order are
  restored locally from private authority.
- A malformed or incompatible surface proposal is rejected item-locally and
  cannot discard valid call-family selections. Unknown refs, request identity
  drift, envelope errors and resource-limit violations remain atomic.
- Exact deterministic Trigger Catalog records win over an equivalent
  model-assisted proposal. The proposal never mutates the local Trigger
  Catalog, Atlas or Canvas.

## Product projection

- An HTTP proposal with an exact locally restored path and registration site
  may publish as a detached declared descriptor. Method and callback remain
  absent unless the provider selects their independently advertised exact
  facts. A callback-bound proposal is an exact static entry surface; a
  path-only proposal is only a navigation lead and never claims a reachable
  endpoint. Action strings such as `METHOD:Action` are not split or promoted.
- A CLI proposal with an exact locally restored command identity publishes as
  a declared model-assisted descriptor; a missing parent or activation never
  becomes an invented command hierarchy. A locally restored callback remains
  optional and exact when present.
- Entrypoints presents these restored records in its existing one-column HTTP
  and CLI groups with exact source actions, bounded/partial truth and no
  automatic Map selection or fabricated component participation.
- Static construction/registration evidence is not execution, runtime order,
  reachability completeness or endpoint availability.

## Bounds and privacy

- Local raw candidates, compiled candidates, facts, per-candidate facts,
  provider request/response and persisted artifacts have independent hard
  ceilings and explicit omission accounting.
- Values are short, single-line and control-free. Candidate facts and the final
  request are credential-scanned; sensitive or high-entropy values are omitted
  locally and counted, never substituted with model text.
- Source paths, line numbers, source bodies, comments, raw graphs, canonical
  IDs and repository trees never cross the provider boundary.
- Capturing the candidate sidecar must not change DirectCallIndex bytes or SHA.

## Acceptance

Provider-free causal tests must prove:

1. Echo-shaped direct calls compile into refs-only route proposals and restore
   exact method/path/callback/source without a framework seed.
2. Restic/etcdctl-shaped keyed command literals compile into refs-only command
   proposals and restore exact command identities/callback locations without a
   Cobra reader or command trace.
3. Invalid bindings, unknown refs, sensitive facts, duplicate proposals and
   bounds fail closed with exact accounting while valid siblings survive.
4. Deterministic local routes override duplicates; model-assisted records do
   not enter Trigger Catalog/Atlas/Canvas authority.
5. Existing entry-call families and legacy accepted artifacts remain readable.

After focused/full tests and vet pass, fresh uncached Russian provider runs on
one Echo application and two Cobra applications are authorized. Browser
acceptance must verify useful HTTP/CLI lists, exact source actions, partial
truth, no framework hardcodes in fresh artifacts, no console errors and no
duplicate deterministic surfaces.

## Non-goals

No full command tree, alias/instance interpreter, route-group prefix invention,
runtime tracing, framework plugin registry, provider-authored paths/symbols,
new model stage, new user option, mobile redesign or model-driven Canvas edge.
