# Decision 202: Exact Architecture input and complete enrichment

## Status

Approved explicitly by the repository owner after the fresh Casdoor report
retained 90 exact Go import edges in `snapshot.json` but sent zero supporting
relations to Architecture, then accepted a model grouping that covered only 15
of 50 explicitly requested members. The owner asked to correct root data and
limit contracts rather than hide the resulting product loss in the UI.

## Outcome

Architecture request construction and authorized report replay use one
byte-identical, authority-bound exact Go package graph. The old Orientation
`important_edges` subset is never an Architecture input. A Go-backed run whose
exact graph cannot be materialized makes zero Architecture provider calls and
publishes the D177 local Canvas with a closed unavailable status; it cannot
claim accepted enrichment over a legacy or partial graph.

Every candidate member advertised in an Architecture request must occur in at
least one returned conceptual component. Many-to-many conceptual participation
remains valid. An incomplete response rejects only model enrichment, without
repair, choose-first assignment, a provider-authored remainder, or any change
to local facts and relations.

Optional Atlas Study domain terms are independent items. A malformed term, an
invalid support ref, or an unsupported locator echo rejects that term only.
The five required Brief statements remain atomic, and valid sibling terms and
directions survive. The prompt requests at most eight terms; output positions
eight and above are unrequested output with bounded closed diagnostics, never
a reason to destroy the Brief.

## Authority and runtime sequence

- the first scoped repository-authority confirmation happens before the
  Architecture call;
- a report-owned authorized compiler produces the exact candidate bundle;
- the complete external provider body is byte-identical when reconstructed for
  saved-response replay;
- the existing post-provider authority reconciliation remains mandatory and
  detects repository changes during external calls;
- exact-graph absence is a provider-free unavailable state distinct from
  offline mode; and
- numeric graph/compiler exhaustion is explicit unavailable or typed resource
  failure, never silent partial success.

No source bytes, raw internal-edge graph, canonical backend identities or full
repository contents become model-visible. The provider receives only the
existing bounded task-shaped package relations and request-local typed refs.

## Contract changes

- component synthesis request/proposal/record contract advances to v7 and the
  prompt to `architecture-grounding-v10`;
- Architecture status advances to v6: accepted evidence requires distinct
  member coverage to equal the exact requested candidate count, and retired
  exclusive-membership/remainder diagnostics remain readable only in older
  status versions;
- `proposal.incomplete_member_coverage` joins the closed status diagnostic
  vocabulary;
- Atlas Study advances to artifact v4 and prompt v10, with item-local bounded
  optional-term diagnostics; and
- earlier caches and artifacts miss closed and are not reinterpreted.

The deterministic documented-purpose projection also converts inline README
HTML entities and line-break tags into plain text before publication. This is a
local presentation projection, not model repair.

## Acceptance

- a saved Casdoor-shaped run sends all 90 exact relations and authorized replay
  reconstructs the same full provider body;
- an incomplete exact graph makes zero provider calls, records
  `exact_workspace_graph_unavailable`, and retains the local Canvas;
- candidate, relation, flow, binding, anchor or research-finding cardinality
  exhaustion is detected before the provider call and returns a typed terminal
  resource error with exact kind, observed count and limit; no prefix is sent;
- complete distinct-member coverage is accepted, including valid repeated
  cross-component membership;
- omitting one requested member rejects the proposal atomically and retains all
  local facts and relations;
- a ninth optional domain term is diagnosed as unrequested while the first
  eight, required Brief and valid routes survive;
- invalid optional-term support, shape or locator text does not discard valid
  siblings; and
- final authority is reconciled after external calls before report, manifest,
  latest pointer or source publication.

One installed live Casdoor comparison follows the provider-free saved-run
gates. Large-repository cardinality limits remain a separate visible
availability boundary; this decision does not claim completeness after those
bounds are exhausted.
